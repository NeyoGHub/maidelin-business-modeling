# maidelin-business-modeling · 使用手册

## 一、三种使用方式

| 方式 | 操作 | 适用场景 |
|---|---|---|
| **① 对话直接说** | 用日常语言提出需求，如"帮我评估XX客户"、"做客户ABC分级" | 最常用，无需记命令 |
| **② 命令调用** | 输入 `/customer-business-modeling` | 明确要用建模方法论时 |
| **③ 自动匹配** | 描述涉及"客户价值/分层/健康度/商品/业务员考核"时自动加载 | 无感知，后台生效 |

## 三、使用示例（3个典型）

**示例1：评估单个客户**
> "帮我评估多乐美便民超市，该不该重点投入？"
> → 输出七维画像 + 结论（如：高价值但回款偏慢31天，重点维护但盯回款）

**示例2：风险排查**
> "找出所有回款超过60天的客户，按欠款额排序"
> → 高危欠款清单（当雄县玉花210天等），附催款建议

**示例3：AI 驱动业务员**
> "今天是周三，给我生成刘亮今天的20家拜访清单"
> → A类预警流失优先 + 高潜B类，每家附推货建议和路线

## 四、使用注意

1. **数据源**：默认对接**麦得邻三件套**（S6 ERP + A8 外勤拜访 + BI），其他 ERP 需先映射表
2. **只读原则**：SKILL 只读数据、输出分析，不改 S6 任何数据
3. **口径**：回款按"销售审核180天+首笔到账"、优惠券按"实际用券"、返利按"2%/3.5%阶梯"
4. **有效拜访**（进店10分钟+3照片）数据在 A8 有缺口，相关指标会标注数据可用性
