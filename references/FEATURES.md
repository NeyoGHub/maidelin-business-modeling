# maidelin-business-modeling · 功能说明书

## 一、核心定位

**麦得邻商贸流通客户业务建模量化系统**——面向使用麦得邻 **S6（ERP）+ A8（外勤拜访）+ BI（商业智能）** 三件套的商贸流通/经销商客户。

**本质**：不是画商业画布，而是**把业务算成数**。基于麦得邻真实业务数据，输出可计算的业务画像（客户/商品/业务员三维），为 **AI 驱动业务员**（该跑哪家、推什么货、精力放哪）提供数据引擎。

**适用行业**：食品饮料批发、快消品分销、商贸流通、经销商。

## 二、当前功能（三大模块）

### 模块一 · 客户建模（七维画像 + 新客留存）

| 维度 | 功能 | 数据依据 |
|---|---|---|
| **活跃度** | 活跃四档(≤45活跃/46-90潜在/91-180流失/>180无效)，取全历史最近开单 | S6 销售单 |
| **新客留存(cohort)** | 首单月→M1/M2/M3 复购率，标出流失环节与新客召回清单（T+1/T+7/T+14/T+30） | S6 销售单（脚本 06） |
| **客户利润** | 销售金额 - 商品成本 - 退货全额 + 退货成本 - 报损成本 - 费用(已含券)，识别真实价值（剔除费用堆出来的） | S6 销售/退货/费用/优惠券 |
| **退货率** | 客户退货率，虚假繁荣客户预警 | S6 销售/退货 |
| **回款周期** | 销售单→收款单链路，首笔到账，180天窗口，客户维度平均 | S6 收款核销链路 |
| **返利模式** | 协议（2%/3.5%阶梯）/普通（券包），用数据反推客户类型 | S6 优惠券/费用 |
| **客情关系** | 拜访响应 + 新品45天接受度 + 下单稳定 + 业务配合 | A8 + S6 |
| **ABC分级** | 按客户利润降序（前20%A/中50%B/后30%C） | 全部 |

### 模块二 · 商品建模

| 功能 | 说明 |
|---|---|
| **商品 ABC 分级** | 毛利贡献（zyxsdmx.mle）+ 动销率交叉：明星/潜力/走量/淘汰品 |
| **商品策略** | 按客户类型输出：A类推高毛利核心品 / B类推潜力新品 / C类推特价清库 |
| **质量预警** | 高退货产品预警（质量问题） |
| **库存健康** | 临期库存清库（cpkc / BI批次效期） |
| **新品表现** | 新品首销45天铺货/动销追踪 |

### 模块三 · 业务员建模

| 功能 | 说明 |
|---|---|
| **五维画像** | 客户资产 / 业绩产出 / 拜访效率 / 回款能力 / 开发能力 |
| **人效四象限** | 横轴客户数×纵轴户均毛利：标杆/靠堆数/精耕少/待辅导（脚本 07） |
| **动销漏斗** | 覆盖→活跃→动销客户数转化率，看谁手里沉睡客户多 |
| **考核评分** | 拜访数量30% + 有效产出70%（行业动销导向）|
| **每日任务分派** | AI 生成 20 家拜访清单：A类流失预警 > 普通A > 高潜B > 少量C唤醒，每店附推货策略 |

### 模块四 · 异动归因与动作闭环（新增）

| 功能 | 说明 |
|---|---|
| **量价拆** | 销售额=销量×均价×结构 三拆，量化量/价/结构各贡献（脚本 05） |
| **四层归因** | 外部→策略→执行→人员 落到数据支撑，根因追 2 层 |
| **头部集中度** | Top1/Top3 客户与业务员占比，暴露"压在一两个人/客户"风险（脚本 05） |
| **P0/P1/P2 动作闭环** | 诊断→可派活任务单：数据依据/根因/动作/量化目标/责任岗/时间/验证指标（ACTION-FRAMEWORK.md） |

## 三、未来可扩展功能（规划）

### 阶段扩展（按实施路径）

| 阶段 | 功能 | 说明 |
|---|---|---|
| **P2** | 每日拜访清单 + AI 策略 | 建模结果 → 自动生成业务员每日行动指令 |
| **P3** | 数据闭环 | 拜访/下单结果回写，客户升降级自动迭代 |
| **P4** | 管理层驾驶舱 | 客户分布、升降级、业务员质量变化的周报/看板（可接 P0/P1/P2 派活） |

### 深度扩展（业务模块）

| 功能 | 说明 |
|---|---|
| **品类/品牌贡献** | 品类维度贡献/趋势/结构优化 |
| **促销ROI** | 优惠券/费用投入产出分析（真实增量+透支检测）|
| **竞品分析** | 竞品铺货/动销对标 |
| **价格策略** | 客户价格带/毛利优化建议 |
| **资金预警** | 现金流预测、坏账风险名单 |
| **路线优化** | 拜访路线地理聚类、在途最小化 |
| **销售预测** | 客户/商品销售预测（趋势模型）|

### 产品化扩展

| 功能 | 说明 |
|---|---|
| **多客户模板化** | 一套 SKILL 服务多个麦得邻客户（数据源可切换）|
| **自然语言问答** | 经营 Q&A（"上个月哪类客户下滑最严重？"）|
| **BI 联动** | 与麦得邻 BI 看板打通，建模结果反哺 BI |
| **移动端** | 业务员手机端收每日任务/提交拜访结果 |

## 四、价值总结

1. **市场下行环境下**：资源向高价值客户倾斜，业务员不迷茫
2. **数据驱动决策**：告别拍脑袋，每个判断有数据支撑
3. **AI 行动指令**：不只给报表，直接告诉业务员今天干什么
4. **麦得邻生态**：深度绑定三件套数据，客户黏性强
