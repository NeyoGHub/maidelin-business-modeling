# P0/P1/P2 动作闭环框架（把诊断变成能派活的行动）

> 本文件是本 SKILL 的**输出规范**：把建模诊断（流失/沉默/高退货/长账期/库存超储/集中度/新客流失）翻译成**能直接派活、事后能验证**的任务单。不需要新数据，是对已有诊断的"表达层"。

## 一、P0/P1/P2 分级语义

| 级 | 时限 | 含义 | 上限 |
|---|---|---|---|
| **P0** | 7 天内 | 止血：直接影响利润/生存，必须立刻处理 | 最多 3 条 |
| **P1** | 30 天内 | 推进：系统性改善的重点 | 3~5 条 |
| **P2** | 90 天内 | 方向：结构优化、机制建设 | 不限，但精选 |

> 节奏参考：**先止血 → 再回补 → 再强身**（T+3 紧急止血 / T+10 短期见效 / T+30 中期改善 / T+90 体系固化）。

## 二、每条动作的 7 要素模板

对每条 P0/P1（P2 可简化为 依据/动作/目标 三要素），按此写全：

1. **数据依据**：这条是哪个数触发的（来源表/口径/数值），可反验。
2. **根因**：归到哪一层、根因追 2 层（外部→策略→执行→人员）。
3. **具体动作**：谁、对谁、做什么，一句话能执行。
4. **量化目标**：做到多少算成（数字）。
5. **责任人（岗位）**：写岗位/业务员，不写"相关部门"。
6. **时间节点**：何时做完。
7. **验证指标**：事后看哪个数判断有没有效。

**一句话模板**：
> P0｜「（根因）」导致（客户/产品/区域）……，依据是（数据）；现安排（责任岗）在（时间）前完成（动作），目标（量化目标），以（验证指标）验收。

## 三、诊断 → 动作模板映射

SKILL 现有诊断产出，直接套对应动作模板：

| 诊断（SKILL 哪来的） | 标准动作模板 | 默认责任岗 | 建议验证指标 |
|---|---|---|---|
| **客户流失预警**（维度1 活跃度 91-180 天） | 7 天内上门/电话回访，问清断进原因，给出本期主推+账期方案 | 该客户维护业务员 | 该客户 30 天内是否恢复下单 |
| **沉默客户**（近90有销+近30无销无拜访） | 派单激活：带新品/特价拜访一次，30 天内是否复购 | 该客户维护业务员 | 复购客户数 / 激活拜访数 |
| **A 类客户流失预警** | 主管亲自跟线回访，必要时老板出面 | 业务员+主管 | 是否保住 / 流失金额 |
| **高退货 SKU（质量预警）**（模块二） | 排查批次/物流/陈列问题，决定退厂或停供 | 采购/商品岗 | 该 SKU 退货率回落 |
| **超账期欠款（>60 天高危）** | 分级催收（先电话后上门），超长账期上报 | 对应业务员+财务 | 回款金额 / 逾期余额下降 |
| **库存超储/临期**（RUNBOOK §5/§6） | 列清仓清单：搭赠/特价/退厂，明确清掉时限 | 库存/业务岗 | 压资金回落、临期清出 |
| **头部集中度风险**（05 脚本⑤） | 分散依赖：给 Top 客户配专属服务、培育二线客户/品 | 销售负责人 | Top1 占比下降 |
| **新客流失**（06 脚本） | 首单后 T+1/T+7/T+14/T+30 分节点回访召回 | 开发该新客的业务员 | M1/M2 复购率上升 |
| **业绩掉量归因**（05 脚本②③④） | 按归因落到责任人：是客户/产品/人员问题就分头整改 | 对应责任岗 | 下期同期对比止跌 |

## 四、输出文体约定（与现有投递一致）

- **纯中文**、可整段全选复制、不用代码块包裹。
- 给老板的：**禁表名/字段名/库名/代码块/JSON/脚本路径**等技术标识；数字可讲，口径一句话带过。
- 给业务员/小组的：可给具体客户名与动作，仍以人能直接执行的话写。
- 每条必带**数据来源可反验**（在 S6 哪个界面能核对）。

## 五、与定时投递的衔接

动作清单可直接作为现有 `fp_*` 推送的结尾段（如周报末尾"本周派活 P0/P1"）。生成规则建议：
- 周报（周日）附"下周 P1/P2 派活"；
- 日报（晚）只在有 P0 时附"明日止血事项"；
- 派活后 2~4 周回来按"验证指标"复盘，结果回写（越用越准）。

> 诊断来源：客户/产品/业务员建模见 `SKILL.md` 模块一~三；异动归因与量价拆见 `SKILL.md` 模块四 + `scripts/05-driver-analysis.sql`；新客留存见 `scripts/06-new-customer-retention.sql`；人效视图见 `scripts/07-salesman-efficiency.sql`。
